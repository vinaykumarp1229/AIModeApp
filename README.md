# AI Mode (WebView wrapper)

Loads Google AI Mode (https://www.google.com/search?udm=50) in a WebView.

## Build the APK
**Android Studio:** Open this folder -> Build > Build APK(s).
Output: app/build/outputs/apk/debug/app-debug.apk

**GitHub Actions (no install):** Push this folder to a new GitHub repo,
open the Actions tab -> "Build APK" -> download the AIMode-debug-apk artifact.
